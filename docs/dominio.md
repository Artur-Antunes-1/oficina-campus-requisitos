# Domínio

O Oficina Campus reúne informações usadas na preparação de oficinas acadêmicas.
A proposta é facilitar a consulta e a manutenção de fichas que costumam ficar
espalhadas em arquivos e mensagens.

## Personas

São personas hipotéticas usadas para orientar o projeto.

| Persona | Objetivo |
|---|---|
| Marina, organizadora | Preparar propostas e manter as informações atualizadas |
| Lucas, pessoa interessada | Consultar orientações e comunicar seus interesses |
| Beatriz, apoio à organização | Encontrar recursos e acompanhar tarefas |

## Vocabulário

| Termo | Significado |
|---|---|
| Oficina | Ficha de proposta com título, apresentação, modalidade e duração |
| Manifestação de interesse | Preferência declarada sobre um tema e uma modalidade |
| Instrutor | Perfil informativo de quem pode compartilhar conhecimento |
| Espaço | Ficha de local com capacidade física informativa |
| Kit | Modelo com uma lista textual de materiais |
| Trilha | Orientação de estudo descrita por objetivo e etapas |
| Arquivado | Registro preservado fora da listagem ativa |
| Visível / oculto | Estado escolhido manualmente para a exibição de conteúdo |
| Situação | Andamento informado manualmente em uma ficha operacional |

## Escopo

O sistema mantém fichas independentes. Manifestar interesse não realiza inscrição;
uma oficina não representa uma turma agendada. Nesta versão não há controle de
vagas, reservas, estoque, presença ou pagamentos. Nomes e títulos podem se repetir.
Os exemplos da interface são fictícios.
